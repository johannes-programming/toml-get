Overview
--------

This project accesses a given TOML file.

Installation
------------

To install ``toml_get``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install toml_get

Typing
------

This project is strictly typed with ``mypy``.

--------
